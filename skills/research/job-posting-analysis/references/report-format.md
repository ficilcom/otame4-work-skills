# 報告書形式

## 1. 記載の要約

求人票に書かれていることだけを、項目ごとに整理する。書かれていない項目は「記載なし」と書く。募集元の法人と実際の就業先が違う場合は先頭に出す。

## 2. 給与の分解

| 項目 | 金額 | 備考 |
| --- | --- | --- |
| 提示年収レンジ | | 求人票の記載どおり |
| 固定残業代 | | 時間数と金額。記載がなければ「記載なし」 |
| 固定残業代を除いた年収 | | 分解できない場合は「分解不能」 |
| 想定労働時間（年） | | 所定 + みなし残業 |
| 時給換算 | | 上記に基づく。前提を明記する |

提示年収をそのまま結論にしない。分解できなかった項目は、何の記載が足りないかを書く。

## 3. 要件の充足状況

| 要件 | 区分 | 充足 | 職務経歴書で示せること |
| --- | --- | --- | --- |

`unknown` は `unmet` に丸めない。応募の可否は書かない。

## 4. 曖昧な条件

記載が不十分で、入社後の条件が確定しない箇所を並べる。各項目に「確定しないと何が変わるか」を添える。

## 5. 確認すべき質問

上の2〜4から、聞く順に並べる。各質問に次を添える。

- いつ聞くか（応募前 / 面接 / 労働条件通知書の受領時）
- 何が確認できれば解消するか
- 書面で確認すべきか口頭でよいか

労働条件は最終的に労働条件通知書で確認する、という前提を明示する。

## 6. 他の求人と比較する場合

固定残業代を除いた基本給と、想定労働時間込みの時給で並べる。提示年収での比較表を作らない。比較できない項目は空欄にし、推定値を入れない。

## 書かないこと

- 採用可能性、通過率、内定確率
- 職種名や業界の常識から補完した業務内容
- 求人票から読み取れない残業実態、社風、評価制度
- 労働条件の適法性の断定
- 企業の評判の評価（`company-research` スキルの範囲）
