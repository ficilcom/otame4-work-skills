# 報告書形式

## 1. いま条件がどこまで確定しているか

先頭に1行で状態を書く。提示が何で来ているか（契約書、発注書、メール、チャット、口頭）とその日付、着手予定日、そして「書面で確定している条件」と「まだ口頭・チャットどまりの条件」の数を示す。

**書面や条件の書かれたメールをまだ受け取っていない場合は、その一点を最初に書く。** 以降の項目がすべて未確定であることを示すため、他の分析より優先する。

契約の型が雇用に見える場合は、ここで先に書く。労働条件の明示が論点になるため `offer-terms-check` に渡し、この確認表は使わない。

## 2. 明示事項の確認表

| 項目 | group | 記載 | 出典 | 書面か | 原文の要点 | 確認すること |
| --- | --- | --- | --- | --- | --- | --- |

- `stated` / `missing` / `unclear` / `unknown` を区別して書く。**未確認を「記載なし」と書かない。**
- 原文の要点は、提示された文言をそのまま写す。「一式」「随時対応」「柔軟に」は、言い換えると範囲が閉じたように見えるため、そのまま残す。
- 対象外の項目（成果物を納めない案件の修正回数など）は、対象外と明記する。該当しない項目を欠落として数えない。
- **着手前に確定させる項目**を先に並べ、残りを後に置く。

## 3. 報酬の換算

| 見方 | 金額 | 前提 |
| --- | --- | --- |
| 予定額 | | 報酬の決め方と、含まれている作業 |
| 支払いの対象になる時間で割った換算時給 | | |
| 無償の作業を含めた総稼働で割った換算時給 | | |
| 自分が負担する経費を引いた後 | | |

- 作業ごとの見込み時間を分けて並べる。打合せ、待ち時間、修正、資料の読み込み、移動、請求書の作成を落とさない。幅がある場合は下限と上限を出す。
- **無償の作業があるときは、その時間と、換算時給がどれだけ下がるかを書く。** 「実績になる」を報酬として数えない。
- 経費、源泉徴収、消費税の扱いが未確定なら、**手取りを計算せず未確定と書く。** 税額を推計しない。
- 相場との比較、単価が高いか安いかの評価は書かない。並べた数字を利用者が読む。

## 4. 支払までの日数

- 納品日（または検査完了日）と支払期日を並べ、日数を書く。
- 起点が受領日か検査完了日か、書面に書かれているかを示す。書かれていなければ確認事項にする。
- 参照する上限の日数は、利用者が一次情報で確認した値を使う。確認していない場合は、日数だけを出し、比較しないと書く。
- 支払期日が書かれていない場合は、それ自体を着手前の確認事項の先頭に置く。

## 5. 週あたりの稼働と、出せる時間

- 見込みの総稼働を、使える週数に配置したときの週あたりの時間を書く。
- 本人が出せる週の時間を超える場合は、範囲を減らすか期間を延ばすかを確認事項にする。どちらを選ぶかは利用者が決める。
- 本業と合わせた合計の稼働は `sidework-rules-check` が扱う。ここでは案件単体の稼働までにする。

## 6. 着手前に確認する質問

上の2〜5から、聞く順に並べる。各質問に次を添える。

- 何が確認できれば解消するか
- 口頭で足りるか、書面・メールでの記載を求めるか
- 着手前に必要か、進めながらでよいか

**着手前に書面で確定させるもの**と、**進めながら決めてよいもの**を分ける。分ける基準は、着手した後で条件を戻せるかどうかである。

条件の変更や追加を依頼する文面は下書きまで作る。通るかどうかは書かない。送るかどうか、いつ送るかは利用者が決める。

## 7. 記録として残すこと

チャットや口頭で合意した条件のうち、書面にないものを一覧にする。日付、相手、内容を利用者自身が記録として残せる形で書く。利用者が明示的に求めない限り、こちらでファイルに保存しない。

## 引き継ぎ

- ここで確定した稼働時間と報酬を `sidework-rules-check` へ渡す。勤務先への申請・届出に書く数字と、本業と合わせた稼働の合算は、そちらで扱う。
- おためし転職の有償業務として受ける案件は、仕事量・期間・報酬の設計と体験後の判断が `otameshi-candidate` の範囲になる。

## 書かないこと

- 受けるべきか、断るべきかの結論
- 報酬が妥当か、相場より高いか安いかの評価
- 条件が適法か違法かの断定
- 源泉徴収、消費税、所得区分を織り込んだ手取りの計算
- 書面にない条件を「普通はこうなる」と補った記述
- 交渉すれば通る、という見込み
- 発注者の評価、継続受注や支払能力の推測
