# 報告書形式

## 1. 一枚目

読み手（決裁者、受け入れる現場、経営者）を先頭に書き、その読み手が先に知りたい問いに1段落で答える。

- 何を確かめるための受け入れか
- 現金でいくら、社内工数が何時間か（金額化した額があれば併記）
- 採用に至らなくても何が残るか
- 誰がいつまでに何を決めるか

## 2. 目的と業務の範囲

解決したい課題、今回確かめたいこと、対象作業と件数、完了基準、対象外を書く。`trial-work-design` の計画があればそこから写し、ないものは書かない。

## 3. 費用の内訳

| 区分 | 内容 | 額または時間 | 出所 |
| --- | --- | --- | --- |
| 候補者への支払い | 基準、実働の幅、経費 | | 計画 |
| 社内工数 | 役割ごとの時間 | | 担当者の見積もり |
| 社内工数の金額化 | 原価の基準があるときだけ | | 社内の基準 |
| 周辺費用 | 掲載料、交通費、備品 | | 公式・見積書・見込み・未確認 |
| 現金で出る額 | 支払い＋経費＋周辺費用 | | |
| 社内工数込みの額 | 金額化できるときだけ | | |

- 現金と社内工数を混ぜない。金額化できない工数は時間のまま置く。
- 未確認の費用があるうちは、現金の額に「未確定」と書く。
- 予算との差は、予算が現金だけか社内工数まで含むかを明記して書く。

## 4. 採用に至らなかった場合に残るもの

成果物、候補者からのフィードバック、受け入れ手順の整備、募集文の改善点を、それ自体の価値として書く。採用の見込みを根拠にしない。

## 5. リスクと止める条件

資料の遅れ、範囲の拡大、途中確認で見直す条件、中止時の精算を書く。中止しても候補者の実施済みの実働は支払う前提であることを示す。

## 6. 他の採用手段との比較

確認済みの金額がある選択肢だけを並べる。金額のない選択肢は名前と「確認中」にとどめる。相場を置かない。優劣は書かず、費用と時間と残るものの違いを並べる。

## 7. 判断事項

| 決めること | 判断者 | 期限 | 必要な確認 |
| --- | --- | --- | --- |

予算、掲載、受け入れ開始、受け入れ担当者の時間確保を分けて書く。

## 引き継ぎ

- 予算が通ったら、`trial-listing-draft` で募集文を作る。稟議の数字（実働、単価、期間）を募集文でも同時に成立させる。
- 金額の理由で通らなかったら、`trial-work-design` に戻して範囲縮小の案を作る。
- 契約形態と支払時期が社内で問われたら、`trial-contract-terms` で発注側の明示事項を確認してから答える。

## 書かないこと

- 採用できる見込み、採用できれば安いという根拠
- 記憶で置いた相場、確認していない他手段の費用
- 金額化の基準がない社内工数の金額
- 候補者の氏名、職歴、選考状況
- 予算に合わせて説明・会議を無償枠に移した計画
