# 報告書形式

次の順で出す。見出しを省略しない。分量が足りない節は「該当なし」と書く。

## 1. 前提

応募区分、企業・職種、設問、制限文字数と数え方の確認状況、提出期限、確認できなかった項目を並べる。未確認は `unknown` と書く。

## 2. 設問ごとの判定

設問ごとに表を1つ置く。

| 観点 | 判定 | 根拠 |
| --- | --- | --- |
| 設問適合 | ok / ずれあり / 判定不能 | 設問が聞いていることと原稿の内容の差 |
| 事実の裏づけ | ok / 要確認 / 不足 | どの主張が `confirmed` / `reported` / `estimated` / `unknown` か |
| 一貫性 | ok / 矛盾あり / 未照合 | 他設問・履歴書との差 |
| 可読性 | ok / 要改善 | 一文の長さ、構成、結論の位置 |
| 分量 | ok / 不足 / 超過 / 未確定 | 現在の文字数と上限 |

## 3. 改稿案

優先度順に並べる。各項目に次を書く。

- **種別** — 削る / 言い換える / 事実を足す
- **対象** — 原稿の該当箇所（引用）
- **案** — 改稿後の文
- **根拠** — なぜその方が設問に答えているか
- **影響文字数** — 増減の目安

「事実を足す」は利用者への質問として出し、こちらで内容を埋めない。

## 4. 利用者への確認事項

回答が得られるまで確定できない点を列挙する。各項目に、確認できない場合に取る代替案を添える。

## 5. 最終稿

利用者が案を選んだあとにのみ出す。変更点、確定した文字数、残った `unknown` を明記する。

## 書かないこと

- 合否・通過率・企業の評価の予測
- 原稿と利用者の発言にない経験、数値、資格
- 応募の送信、企業への連絡、求人サイトの更新の実行
