# 未経験者の見学・学習の受け入れ

未経験者が仕事内容を知るための無償体験を候補にする。今回の作業経験と学びたいことを確認し、経験者でも学習が目的ならその希望を尊重する。実務を任せる場合は経験を問わず [有償業務](paid-work.md) を設計する。

## 活動の選び方

- 職場見学、担当者への質問、架空データによる模擬課題から学習目的に合うものを選ぶ。納品、日常業務の代替、顧客対応、売上や処理件数の達成を求めない。
- 模擬課題の成果は学習とフィードバックに使う。実務に使う成果が必要なら、その作成を無償枠に含めない。「課題」「研修」の名称や本人の同意だけで無償にできると判断しない。
- 少ない時間で確かめられる内容に絞り、学習目的がない作業の繰り返しや無償期間の延長を提案しない。

## 受け入れ計画と募集文

| 項目 | 定義すること |
| --- | --- |
| 学習目的 | 参加者が仕事内容や働き方について知れること |
| 活動と時間 | 見学・説明・模擬練習・質問の配分、対面かリモートか |
| 担当者と支援 | 説明、質問対応、フィードバックの担当と確保時間 |
| 資料と場所 | 架空・公開資料、見学可能な範囲、秘密情報や安全面の準備 |
| 費用と変更 | 報酬なしという提案、交通費等の負担、日程変更・中止時の連絡方法 |
| 振り返り | 参加者の理解・疑問を聞く機会と、次に確かめること |

募集文には体験の目的・活動・時間・企業の支援を具体的に書く。「未経験でも即戦力として無償で貢献」「採用まで無料で実務」といった内容にしない。未決定の担当・日時・費用は原稿外で確認し、採用や有償契約への移行を保証しない。

完全に架空の例：営業事務の説明15分、見学20分、架空の注文票を使う模擬練習15分、質問と振り返り10分の計60分。実注文の処理は対象外とし、説明担当者が同席する案にする。これは標準時間ではなく、利用者の制約に合わせて調整する。

## 実施前・内容変更時

[公式情報](source-checks.md) で活動の実態に関わる扱いと無償体験の掲載可否を確認する。掲載可能か不明なら、確認事項を付けた下書きとして返す。依頼された他の準備まで止める必要はない。

企業が実務への切り替えを求めたら、対象範囲、実働、報酬、契約条件を改めて整理する。双方の合意が得られるまでは実務を割り当てる案にしない。
