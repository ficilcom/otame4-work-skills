# 企業の振り返りとフィードバック

事前に決めた業務範囲・完了基準と、実施メモ・成果物の確認結果を突き合わせる。採用の最終判断は担当者に残し、職務に関係する根拠を整理する。

| 論点 | 整理する内容 |
| --- | --- |
| 観察事実 | 実際の行動、実施内容、成果。誰が何を確認したか |
| 事前の期待 | どの完了基準を確認できたか。後から追加した期待は分ける |
| 支援と制約 | 説明・資料・権限・レビューの提供、未提供や待ちによる影響 |
| 未確認 | 時間不足や今回の業務外で、判断できなかった能力・協働の場面 |
| 次の対応 | 継続、追加確認、見送りの判断材料と、担当者が決める事項・時期 |

- 短い体験や一度の失敗から性格・適性・将来の活躍を断定しない。職務と関係のない属性で評価・順位付けしない。
- 無償の学習体験は、学んだことや質問・理解を振り返る。企業の実務成果を評価基準にしない。
- 成果不足の場合は、実施済み、未完了、追加希望を分ける。企業の説明・資料不足も確認し、候補者だけの責任と決めつけない。
- 報酬の精算は [有償業務](paid-work.md) の合意条件で確認する。採用判断や企業の満足度と混ぜず、雇用で賃金ゼロ、無償でのやり直し、無期限の延長を提案しない。

フィードバック案は具体的な作業事実、よかった点、改善・追加確認したい点、担当者が選んだ次の対応から作る。企業が継続を決めていなければ継続決定の通知にしない。受け入れ担当者用の判断メモと候補者に伝える文面を分け、他候補者の情報・内部評価を混ぜない。

レビュー公開の依頼は、[公式情報](source-checks.md) で公開範囲や変更可否を確認し、必要以上に候補者を特定しない下書きにする。返信・公開は本人が行う。
