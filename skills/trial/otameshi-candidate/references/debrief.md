# 求職者の振り返り

体験前に確かめたかったことと、本人のメモを突き合わせる。メモが少なければ、実際にした作業か気になった場面を一つ尋ね、書ける部分から整理する。

| 論点 | 整理する内容 |
| --- | --- |
| 期待と事実 | 期待していたこと、実際の作業・発言・出来事、分かった範囲 |
| 感想と解釈 | 楽しかった、不安だった等の感想と、そのきっかけ。職場全体への評価に広げない |
| 支援と条件 | 説明・レビューの有無、事前の条件との一致・差、必要だった支援 |
| 未確認 | 普段の業務量、長期の働き方など、今回だけでは分からなかったこと |
| 次の行動 | 継続、追加確認、見送りそれぞれの根拠と、判断前に聞くこと・確認時期 |

「楽しかったから入社」「指摘されたから不採用」とは結論づけない。継続を考える場合も、体験時と入社後の業務・契約・報酬条件を同一視せず、書面で確認する項目を出す。

予定の成果に届かなかった場合は、実施済みの作業、支援や資料の不足、残った作業を分ける。精算については [有償業務](paid-work.md) の条件に戻り、成果不足を理由に自主的な無償延長や賃金放棄を勧めない。

相手に返すフィードバックは、具体的に学んだこと・確認したいこと・本人が選んだ次の希望から下書きする。内部の比較メモ、他社の選考状況、非公開の業務情報は含めない。公開レビューを求められた場合は公開範囲や変更可否を [公式情報](source-checks.md) で確認し、公開用の下書きと注意すべき未確認事項を返す。投稿は本人が行う。
