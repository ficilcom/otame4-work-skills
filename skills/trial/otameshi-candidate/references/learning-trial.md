# 未経験分野の学習体験

## 体験を選ぶ

知りたい仕事内容と、今回未経験の作業から活動を選ぶ。短い見学、担当者への質問、架空データによる模擬課題などを候補にし、本人の時間・負担・希望に合わせる。「未経験だから無給で働く必要がある」とは勧めない。

無償体験の候補では、企業の納品物、日常業務の代替、顧客対応、売上・処理件数の達成を求めない。課題の成果を企業が実務利用する予定なら、その部分を有償業務として切り分ける。本人の同意や「研修」という名称だけで無償にできると判断しない。[公式情報の確認](source-checks.md) に従い、活動の実態とサービス上の扱いを確認する。

## 本人が選べる計画を作る

次の内容を依頼に必要な範囲でまとめ、未合意の時間や企業の支援は提案と明示する。

| 項目 | 内容 |
| --- | --- |
| 学習目的 | 仕事内容、協働、働き方について確かめたいこと |
| 活動 | どこを見学し、誰に何を聞き、どんな模擬作業を試すか |
| 時間・場所 | 本人が使える時間、各活動の配分、対面・リモートの希望 |
| 企業の支援 | 説明・質問対応・フィードバックを誰にお願いするか |
| 扱う資料 | 公開・架空・閲覧許可済みの情報。現職や顧客の秘密を持ち込まない |
| 費用・変更 | 報酬なしという提案と、交通費などの負担、変更連絡の方法を別々に確認 |
| 振り返り | 終了時に何を言葉にできれば目的を確かめられるか |

例えば完全に架空の相談なら、営業事務を知りたい人に、説明15分、見学20分、架空の注文票での模擬練習15分、質問と振り返り10分の計60分を提案できる。実際の注文処理や納品は含めない。この時間は固定の標準ではない。

## 応募・実施時の確認

- 希望する学習内容と経験の範囲を短い応募文にし、企業が提供できる説明や支援を質問する。参加だけで採用につながると示さない。
- 無償体験の掲載・申込がサービスで認められるか未確認なら、原稿を「掲載・申込可否の確認前の案」とし、運営へ確認する質問を付ける。利用可能と断定しない。
- 当日実務を頼まれた場合は、対象業務、時間、報酬、契約条件を改めて確認する返信案を作る。有償条件が未合意のまま実務に移ることを勧めない。
