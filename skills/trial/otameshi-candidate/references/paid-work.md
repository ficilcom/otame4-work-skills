# 有償おためし業務の確認と提案

企業が期待する仕事と本人が提供できる作業・時間を照合する。経験のある作業を小さく切り出す。未経験の部分は必要な説明やレビューを明示し、無償で埋め合わせない。

## 同じ条件表に揃える

| 項目 | 確認・提案する内容 |
| --- | --- |
| 目的と業務範囲 | 解決する課題、対象作業・件数、対象外、本人の経験との接点 |
| 成果・完了基準 | 提出物または実施内容、品質、確認方法・担当者。売上等の外部要因を成果保証にしない |
| 仕事量 | 説明、準備、作業、会議、レビュー、修正、振り返りの実働見積もりと前提 |
| 実施期間 | 開始・終了、週の稼働、途中確認、資料提供・返信待ち。実働時間とは別に示す |
| 企業の準備と支援 | 資料、アクセス権、説明担当者、レビュー時間、提供予定 |
| 報酬 | 契約形態、時間単価・固定額等の基準、予定総額、経費、税の扱い、支払日・主体 |
| 変更・終了 | 追加業務、修正の回数・時間の範囲、延長・中止時の連絡と精算の確認事項 |

各条件に提示元・時点と、企業提示／本人希望／提案／双方合意／未確認を付ける。求人・チャット・契約資料の食い違いを、都合のよい方に統一しない。秘密情報、成果物の利用・権利、現職の副業手続きも必要な範囲で確認する。

## 時間と費用を検討する

- 実働の合計と週の上限を計算してから期間に配置する。説明や必要な打合せを見積もりから落とさない。求職者の時間と企業担当者の時間は分け、二重計上しない。
- 見積もりに幅があるなら幅と増減要因を示す。情報が少ない場合は仮置きの業務案と必要な確認を返し、作業時間を確約しない。
- 時間単価が提示されている場合は単価×予定実働で予定額を示す。経費・税の含み方が不明なら別記する。単価がなければ相場を創作せず、必要時間と単価の確認質問を出す。
- 固定額なら対象範囲と修正条件を確認する。固定額÷見積時間の換算は比較用であり、時間単価の契約や適法性を意味しない。
- 予算や稼働に収まらないときは、対象を減らす案、予算を増やす案、期間を変える案を比較する。期間だけ延ばしても総実働と費用は減らない。本人が同意していない残業や追加作業を約束しない。
- 資料提供待ちで作業不能なら影響する業務と日程を示し、提供後に日程を再設定する案を作る。待ち時間を有給・無給と自動で決めず、契約と拘束の実態を確認する。

## 支払いと評価を区別する

成果への期待、仕事の完了確認、報酬条件、採用の判断は別々に扱う。雇用なら成果への不満や不採用を理由に賃金をゼロにする案は作らない。業務委託と記載されていても名称だけで法的扱いを決めず、支払い・検収・修正条件の不明点を質問にする。法令や最低賃金が判断に関わる場合は [一次情報](source-checks.md) を確認し、個別の法的判断は専門家への確認事項にする。

返すのは、本人が検討できる条件表と、企業への確認・調整の返信案。相手が未回答の条件を「承諾します」に含めない。
