# 報告書形式

## 1. 日程

| 項目 | 日付 | 備考 |
| --- | --- | --- |
| 内定承諾 | | 未承諾なら、退職の申出はまだ行わない |
| 退職の申出 | | 就業規則の期限との関係を書く |
| 退職日 | | |
| 入社日 | | |
| 空白期間 | | 日数と、発生する手続き |

就業規則の定めに間に合わない場合は、**間に合わないという事実と、調整の選択肢**を書く。どれを選ぶかは利用者が決める。「規則を無視できる」とも「不可能だ」とも書かない。

## 2. 手続きの状況

| 手続き | 状態 | いつまでに | 備考 |
| --- | --- | --- | --- |

着手していないものを上に出す。期限のあるもの（健康保険の切替、年金、確定拠出年金の移換）は、**期限そのものを断定せず、どこで確認するかを書く。**

## 3. 受け取るもの・返すもの

| 区分 | 物・書類 | 状態 | 備考 |
| --- | --- | --- | --- |

未確認のものを「不要」と書かない。会社によって発行の要否が違う項目は、確認事項として残す。

## 4. 引き継ぎと守秘

- 引き継ぎの範囲と期限
- 持ち出してはいけないもの
- 退職後も続く義務（守秘、競業避止）の確認箇所

競業避止条項がある場合、条項の存在と範囲を書く。**有効性の判断はしない。** 内容が業務に関わる場合は、専門家への相談を選択肢として残す。

## 5. 伝え方

上長への申出の場で伝える内容を整理する。**文面の下書きは作れるが、伝達も送信も自動で行わない。**

- 伝える相手と順序（直属の上長が先）
- 伝える内容（退職の意思、希望する退職日、引き継ぎの見通し）
- 伝えないと決めること（転職先の社名、次の年収、他社の選考状況）

引き止めへの応答も、あらかじめ決めておく項目として並べる。**受けるか断るかを、こちらで決めない。**

## 6. 利用者が確認すること

就業規則、雇用契約書、給与明細、健康保険組合の案内、確定拠出年金の資料。どこに何が書いてあるかを示し、確認できるまでは `unknown` のまま残す。

## 書かないこと

- 退職できるかどうかの法的な結論
- 就業規則と法令のどちらが優先するかの断定
- 有給の買い上げや退職金の額の見込み
- 競業避止条項の有効性の判断
- 円満に退職できるという見通し
- 退職代行の推奨
- 引き止めを受けるべきか断るべきかの結論
