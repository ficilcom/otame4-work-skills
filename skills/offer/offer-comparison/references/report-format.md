# 報告書形式

## 1. 何を比べているか

先頭に、比較の前提を書く。各内定の条件が**どこから来たか**（労働条件通知書、内定通知書、口頭、求人票）と、書面で確認できていない内定があればその一点を最初に出す。

書面で確認していない条件を含む比較は、比較そのものが仮のものになる。順序を入れ替えて書かない。

## 2. 分解した金額

| 指標 | A社 | B社 | 差 |
| --- | --- | --- | --- |
| 提示年収（記載どおり） | | | |
| 基本給＋固定手当の年額 | | | |
| 固定残業代の年額（時間数） | | | |
| 賞与の年額（保証の有無） | | | |
| 変動しない年額 | | | |
| 想定年間労働時間 | | | |
| 提示年収の時給換算 | | | |
| 変動しない年額の時給換算 | | | |

- 提示年収の行だけで結論を書かない。**変動しない年額と時給換算まで見せてから**、どこで順序が入れ替わるかを指摘する。
- データが欠けている指標は行ごと落とすか、欠けている会社を空欄にして「比較不能」と書く。推定値を入れない。
- 内訳の合計が提示年収と合わない内定は、差額と、何が含まれているか不明かを書く。

## 3. 金額に換算していないもの

| 項目 | A社 | B社 |
| --- | --- | --- |
| 退職金・企業年金 | | |
| 住宅補助 | | |
| 通勤手当 | | |

年額に足し込まない理由（実費の補填、課税扱いが不明、受け取りが将来）を1行添える。

## 4. 金額にならない条件

| 項目 | A社 | B社 |
| --- | --- | --- |
| 勤務地・転勤の範囲 | | |
| 労働時間制度・休日 | | |
| 業務内容・配属 | | |
| 契約期間・試用期間 | | |

記載のまま並べる。**優劣をつけない。点数化しない。合計点を出さない。**

## 5. 確認すべきこと

比較が成立していない箇所を、確認事項に変える。各項目に、誰にいつ聞くか、書面で求めるかを添える。承諾期限が近い内定から順に並べる。

## 6. 利用者が決めること

最後に、判断が分かれる軸を並べて返す。こちらで結論を出さない。

- 変動しない年額を取るか、上振れの可能性を取るか
- 時間あたりの条件を取るか、額面の総額を取るか
- 勤務地・転勤の範囲をどこまで許容するか
- 何年後を基準に見るか（初年度の額面か、昇給と退職金を含めた長期か）

利用者が重視する軸を聞いた場合は、その軸で並べ替えて見せる。並べ替えは重み付けであって、正解ではないと明記する。

## 書かないこと

- どの内定を受けるべきかの結論、推奨、順位
- 総合点、スコア、星の数
- 企業の将来性や安定性の推測（`company-research` の範囲）
- 手取り額の断定
- 交渉すれば条件が上がるという見込み
- 辞退する内定への評価
