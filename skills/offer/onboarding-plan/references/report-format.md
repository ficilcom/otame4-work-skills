# 報告書形式

## 1. 日程

| 項目 | 日付 | 備考 |
| --- | --- | --- |
| 今日 | | |
| 入社日 | | 入社までの日数 |
| 試用期間の終わり | | 計算した日付なら、会社の定めで確かめると添える |
| 試用期間の基準を確かめる期限 | | 終わりの30日前を目安に |

労働条件の書面をまだ受け取っていない場合は、表の前にその一点を書く。

## 2. 期待と約束の一覧

| 項目 | 内容（聞いたとおり） | 出典（誰が・いつ） | 書面 | 測り方 | 確かめる相手 |
| --- | --- | --- | --- | --- | --- |

- 口頭だけで、まだ確かめていない項目を上に出す。
- 内容は聞いたとおりに書き、言い換えない。
- 出典によって食い違う項目は、行を分けて両方の内容を並べ、「確かめる」とだけ書く。どちらが正しいかを推測しない。

## 3. 試用期間

期間、期間中の条件が本採用後と同じか、本採用の判断基準、延長の有無を並べる。分からない項目は `unknown` のまま書き、誰にいつ聞くかを添える。適法性は判定しない。

## 4. 入社前にすること

| すること | 期限 | 状態 | 備考 |
| --- | --- | --- | --- |

手続き書類は名前だけを書く。期限と要否は会社の案内で確かめると添える。入社前の研修・課題がある場合は、賃金の扱いと参加の要否を確かめる項目にする。

## 5. 確かめる場と質問

場ごとに、日付、相手、そこで確かめる項目、質問の文面を書く。

- 質問は、聞いた内容と相手を示し、相手が訂正できる形にする。
- 入社前の相手（採用担当者）と、入社後の相手（直属の上長）を分ける。
- 場が決まっていない項目があれば、どの場で確かめるかを提案する。日付と相手は利用者が決める。

文面の下書きは作るが、**送るか、いつ聞くかは利用者が決める**と明記する。

## 6. 記録として残すこと

確かめた内容のうち、書面にないものを、日付・相手・内容の形で利用者自身が残せるように書く。利用者が明示的に求めない限り、こちらでファイルに保存しない。

## 引き継ぎ

- 労働条件の書面に不足や食い違いがある → `offer-terms-check`
- 退職の手続きや前職の書類の受け取りが残っている → `resignation-plan`
- 入社後に「聞いていた話と違う」と感じて、続けるか迷っている → `job-change-decision`

## 書かないこと

- 試用期間を通るか、職場に馴染めるかの見込み
- 上司、同僚、会社、社風の評価
- 試用期間の定めや本採用の判断の適法性
- 成果を約束する目標や計画
- 前職の資料や顧客情報を持ち込む準備
